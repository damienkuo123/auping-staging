AUPING STATIC RECONSTRUCTION V3

Open: index.html or en/index.html

This version replaces the screenshot-slice/hotspot implementation from V2.
All supplied category pages are now built from real HTML sections, reusable CSS components and JavaScript interactions. Individual photos/products are local image assets cropped from the supplied page captures; the pages themselves are not screenshots.

Included:
- Homepage
- Box springs, Beds, Mattresses, Toppers, Bed bases, Bed linen, Pillows
- Working local product detail pages
- Basic local configurators
- Store locator demo
- Search dialog, mobile menu, filters, read-more interactions
- File-protocol routing fix: clean directory links open index.html instead of the browser directory listing

Remaining differences from the live Auping site:
- Videos are still images with simulated controls
- Store map and results are demo data
- Product filters use reconstructed local tags, not the live database
- Product details/configurators are reconstructed templates, not the original Drupal/Magento data or 3D configurator
- Some long-form pages not supplied as screenshots use a consistent reconstructed template
- Exact original fonts and source media were not available
