# Known limitations

- Google Maps iframe rendering requires internet access and can be affected by Google policy, regional availability or browser privacy settings.
- The local project does not own a verified Taiwan Auping dealer dataset; therefore no local dealer markers or opening hours are invented.
- Searching uses Google Maps query results. The official Auping Store Locator link remains visible for authoritative dealer data.
- Browser geolocation requires user permission and usually requires HTTPS; GitHub Pages satisfies the secure-context requirement.
