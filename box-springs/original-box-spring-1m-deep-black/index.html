                      Original Box Spring

                      Original Box Spring 採用歷久彌新的設計，重視細節與高品質作工。床腳配置讓整張 Box Spring 呈現些微懸浮的視覺效果。提供 8 款床頭板與 95 種布料，可依喜好完整自訂 Original Box Spring。想進一步了解 Original Box Spring？歡迎查看線上 Lookbook。

                      Original Box Spring 配件 

                      以精心搭配的配件，讓你的 Auping Original Box Spring 更加完整。    

                      你可以在配置器中加入或調整配件，打造理想中的 Original Box Spring，包括床尾板、包布床頭板、床邊桌或不同顏色的床腳。

                       

                      選擇適合你的床墊與舒適墊

                      此 Original Box Spring 組合包含 Comfort 床墊與 Comfort 舒適墊。若想更換搭配，Original Box Spring 可搭配 Auping 全系列床墊與舒適墊，並可在配置器中調整選擇。
