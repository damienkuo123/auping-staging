                      Auping Original Box Spring

                      歷久彌新的設計

                      歷久彌新的設計，加上對高品質作工的重視，這就是 Original Box Spring。 巧妙配置的床腳，讓 Box Spring 在你入睡之前就彷彿懸浮於空中。 
                      透過 95 種 種布料與 8 款 款床頭板，你也可以把 Box Spring 打造成最符合自己喜好的樣貌。 若想為臥室加入低調色彩，可以從 10 種顏色中挑選 Box Spring 床腳。

                      網狀床底、獨立筒彈簧與床墊共同提供出色通風與支撐，讓睡眠更舒適。

                      Box Spring 的層次結構

                      Original Box Spring 內部配置完整，包含網狀床底與獨立筒彈簧。
                      每一層都有自己的優勢。Box Spring 與床墊中的獨立筒彈簧讓你夜間翻身更自在，同時提供良好支撐。網狀床底有 80% 的開放結構，讓整套 Box Spring 擁有優異通風；獨立筒彈簧與網狀床底共同幫助你獲得充分休息。

                      Box Spring 的床墊選擇

                      選好床座後，下一步就是挑選床墊。床墊位於床座上方，可選擇包布款或白色款；若選擇包布床墊，上方還會再搭配一層舒適薄墊。

                      無論是否包布，所有床墊都透過獨立筒彈簧提供合適支撐。要真正了解哪一款最適合你的身體與需求，最好到門市親自試躺。包布床墊會搭配舒適薄墊；這一層主要決定躺感，而非支撐性，因此親自體驗最能感受差異。

                      總有一款 Auping 床墊適合你的理想睡眠。床墊提供柔軟、中等、偏硬與特硬四種硬度。負責支撐的獨立筒彈簧專為 Auping 開發，並經測試中心充分驗證；每個彈簧都能獨立運作，在身體真正需要的位置提供支撐。

                      進一步了解我們的 Auping 床墊，以及 包布床墊 以及 舒適薄墊. 

                      Original Box Spring 的布料選擇

                      只有真正符合你的喜好，Auping Box Spring 才算完整。Original Box Spring 可從 Auping 布料系列的 95 種布料中挑選包覆，共分為 5 組布料：

                      • 布料組 A： 這些是帶有細緻紋理的純色基本布料。Grid、Peach 與 Salt 三款皆以聚酯纖維製成。我們特別喜歡此組中的 Grid Denim，呈現明亮漂亮的藍色。
                      • 布料組 B 包含具有獨特組織的布料。Points、Maze 與 Dew 都擁有出色觸感；例如 Dew 帶有柔軟天鵝絨般的感受，而 Points 與 Maze 則非常耐用。
                      • 在 布料組 C 可找到兩款溫暖、濃郁且具有幾何感的布料：Facet 與 Reflect。兩款布料皆在歐洲鄰近地區生產。 
                      • 布料組 D 包含 3 款高級羊毛布料，皆來自丹麥布料製造商 Kvadrat：Clara、Remix 與 Re-wool。
                      • 布料組 E 包含三款奢華且具獨特性的布料。針織 Plecto、Sprinkles 與 Jaali 能與 Auping 系列其他布料漂亮搭配，為臥室增添精緻質感。

                      Original Box Spring 的床頭板與床尾板

                      搭配床頭板與床尾板後，Auping Box Spring 才真正完整。你可以從八款 Original Box Spring 床頭板，以及 1 款床尾板。所有款式皆在 Deventer 的縫製工坊手工包覆，四周完整覆布，因此即使將 Original Box Spring 放在房間中央，從背面看也同樣美觀。

                      Original Box Spring 的 8 款床頭板：

                      - Dublin：現代俐落，中間帶有裝飾縫線的床頭板。
                      - Mute：沉穩簡潔，四周以滾邊收尾的床頭板。
                      - Wink：帶點俏皮與叛逆感的床頭板。
                      - Nice：厚實而有存在感的床頭板。
                      - Bold：厚實穩固，適合舒適倚靠的床頭板。
                      - Portofino：高款經典床頭板，以弧形圓扣細節收尾。
                      - Line：柔和的矩形床頭板，搭配垂直縫線。
                      - Valencia：柔軟、鬆身包覆的床頭板，以均勻分區縫線營造幾何視覺效果。

                      這 8 款床頭板皆可搭配 Siena 床尾板；其線條俐落，設計歷久彌新。

                      可選型號

                      Original Box Spring 提供多種不同款式。
                      單人 Box Spring 提供 80、90、100 或 120 公分寬，以及 200、210 或 220 公分長。
                      雙人 Box Spring 提供 140、160、180 或 200 公分寬，以及 200、210 或 220 公分長。

                      可分離式

                      完整雙人 Box Spring 的可分離版本在床腳下方配有滑輪，能輕鬆將兩側分開或推回，方便鋪床、清潔臥室，也更容易觸及各個位置。

                      在 Auping Box Spring 上神清氣爽地醒來

                      良好的床底在 睡眠時非常重要。你與床墊都獲得良好支撐，才能夜夜安心入睡。
                      合適的床底也能讓床墊擁有更好的透氣性，延長良好使用狀態。我們建議床墊使用 8 年，最長約 10 年後更換。

                      Auping 重視每張床的最佳通風，因此我們的 Box Spring 同樣採用網狀床底。Auping 網狀床底以編織鋼材製成，形成細緻開放的結構；由於開孔率達 80%，能帶來格外優異的通風效果。

                      更多支撐：可調式 Box Spring

                      Original Box Spring 也提供可調式 Box Spring 版本。當你想閱讀、腰背不適、持續咳嗽，或只是晚上想看電視時，可調式床能帶來更高的舒適性。

                      可調式 Box Spring 提供三種不同模式，你可以只調整背部、調整背部與腿部，或選擇背部、腿部與頭部三個區域全部可調。

                      你可以調整 Box Spring ，可使用遙控器或 Auping Connect。透過 Auping Connect，你可以使用智慧型手機操作可調式床。遙控器可收納在固定於床側、並使用與床體相同布料製作的收納袋中。

                      Original Box Spring 在床座與床墊之間設有牢固的魔鬼氈，即使調整 Box Spring 角度也不易滑動；造型精緻的扣件與固定環則能將舒適薄墊固定於床墊上。

                      荷蘭 Deventer 的工藝製作

                      Original Box Spring 在我們位於 Deventer 的工廠中，以部分手工、部分機械方式製作。我們將手作工藝與最新科技、人體工學及設計發展結合。每一組 Box Spring 都兼顧細節、環境與未來；我們非常重視打造能長久使用的產品。

                      因此，我們選用優質材料，並盡可能與鄰近供應商合作。我們把每個細節都先替你想好。
