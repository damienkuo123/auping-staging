床架與 Box Spring 床組

如何安裝或拆卸 Auping 床架／Box Spring 床組？
在我們的 使用說明書 頁面可以找到各款床架與 Box Spring 床組的說明，依步驟自行組裝或拆卸。若沒有找到你的型號，請聯絡 Auping 官方客戶服務。

Auping 床架／Box Spring 床組的備品零件要去哪裡取得？
大小備品零件可透過 Auping 門市洽詢。建議提供床架缺少零件的位置照片，或直接拍攝零件本身，方便門市協助確認正確品項。

床架／Box Spring 床組有客訴或問題時該找誰？
若是在 Auping 台灣門市購買，請先聯絡原購買門市；若是透過 Auping 官方線上服務購買，請聯絡官方客戶服務。實際可用的線上購買服務依台灣市場提供內容為準。

產品交期多久？
Auping 官方產品頁會提供交期資訊；台灣實際交期請以台灣門市或官方服務確認為準。

床架或 Box Spring 床組可以不含床墊及／或網狀床底單獨購買嗎？
Auping 官方 Configurator 可依產品設定選擇床架或 Box Spring 床組配置；台灣可訂購的組合仍以官方服務與門市供應為準。

床架或 Box Spring 床組配件可以透過網路商店單獨購買嗎？
Auping 官方英文頁面指出，相關配件並非都能單獨在線上購買；台灣是否可單獨訂購，請洽 Auping 台灣門市。

床架或 Box Spring 床組有現貨嗎？
Auping 官方資料指出，床架與 Box Spring 床組採依訂單生產，因此不以一般現貨庫存方式供應；台灣實際供貨狀況仍以門市確認為準。

Auronde Restyle 如何使用／申請？
Auping 官方英文頁面指出，Auronde Restyle 可透過 Auping 門市辦理，費用會依床頭板、邊桌或後方元件等項目而異，部分舊系列型號也可能不適用；官方英文頁面所列價格自 €750 起。此價格與服務範圍不代表台灣報價或供應，台灣是否提供 Auronde Restyle 及實際費用請洽 Auping 台灣門市確認。
