# Update workflow

```text
Original-site change
  → review public differences
  → update local content/assets
  → update hybrid-functions.json when an official URL changes
  → run static verification
  → push to staging
  → browser smoke test at 1440 / 768 / 390
  → publish
```

Do not run a full capture or 809-page audit for routine copy or image updates. Reserve those operations for major site revisions.
